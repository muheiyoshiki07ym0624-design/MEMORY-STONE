# MEMORY STONE

端末内に旅と石ころの記録を保存する、ブラウザ向け試作品です。

## 起動方法

Python 3 が利用できる環境で、プロジェクトのルートから次を実行します。

```sh
python3 -m http.server 4173 --directory outputs
```

ブラウザで <http://localhost:4173> を開いてください。カメラを利用する場合は `localhost` または HTTPS で開き、ブラウザのカメラ利用を許可します。カメラ映像は表示しますが、石ころの画像認識は未実装です。

## 保存について

記録と画像は IndexedDB に保存され、このブラウザ内に残ります。写真は保存前に JPEG に縮小します。別ブラウザや別端末とは同期しません。サンプル記録は最初の起動時に追加され、編集・削除の対象外です。ユーザーが登録した記録は編集・削除できます。

サンプル写真の表示にはインターネット接続が必要です。登録した写真は端末内に保存されます。
